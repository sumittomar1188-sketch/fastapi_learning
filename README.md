# FastAPI Learning & Projects

This repository documents my journey of learning **FastAPI** and applying it to build real-world backend applications.

## What I Learned

- FastAPI fundamentals and application structure
- Path and query parameters
- Pydantic models and data validation
- HTTP methods and API development
- Request and response handling
- ML model integration with FastAPI
- Backend deployment using Docker

## Project: Insurance Premium Prediction API

As part of my learning, I built a backend API for an **Insurance Premium Prediction** application.

- Developed the backend using FastAPI.
- Integrated a machine learning model for insurance premium prediction.
- Created an API endpoint to accept user inputs and return predictions.
- Containerized the backend using Docker.
- Successfully deployed the backend on **Zoho Catalyst AppSail**.
- Built a small Streamlit frontend to interact with the deployed API.
